# 测试流程变更说明

## 目标

为现有 TDT 演示增加无窗口自动测试、失败耗时、结果表和任意历史测试的手动复现。
先建立本说明，再实现和验证；使用方法见实现完成后提供的 `BenchmarkUsage.md`。

## 计划变更

- `main.cpp`、新增 `src/benchmark/`：共用测试执行、随机取点、计时和演示。
- 新增 `scripts/run_benchmark.py`：启动 C++ 测试，保存日志、输入、轨迹和统计报告。
- `minimumSnap.hpp/.cpp`：增加退出原因等诊断，不改变优化目标、碰撞容忍和求解限制。
- CMake、测试和相关文档：接入新流程，验证原有功能。

默认仍以当前时间作为随机种子；种子、地图和参数随结果保存。不增加地图配置文件。
随机范围由图片尺寸决定，分辨率由命令行指定，默认 0.05 米/像素。

## 兼容性和计时

重新编译后 `cd build && ./play` 仍为手动演示。自动模式不创建窗口。
各阶段和单次总耗时由 C++ 的单调时钟测量；总耗时包括初始化至验证，
不包括读图、绘图、等待按键、结果写盘。Python 另记录整个批次的墙钟耗时。
新计时口径和随机取点方式与旧版不同，不直接对照旧性能表。
搜索算法、优化目标、碰撞容忍和求解限制保持不变，OSQP 内层超时 setter 的已知问题不在本次修复。

## 实施与验证

已实现上述流程。随机点采用自由栅格中心，所有历史模式优先使用保存的内部米制坐标，
避免再次经过旧版整数 Y 翻转而偏移。默认地图保留原示例，显式换图默认只测随机规划。

验证结果（2026-11-21）：

- CTest 两个目标通过：原求解回归及新增测试框架集成验证；集成验证含 5 项测试。
- 原取点工具 4 项 Python 回归通过。
- 实际窗口验证通过：C++ 演示显示、按键切换下一例、Q 退出，以及 Python 原始轨迹回放。
  当前桌面为 Wayland，自动按键验证使用 X11 兼容模式。
- 换用 `inside_map.png` 完成 10 例测试，7 例通过，无需改源码。
- 最终默认完整测试保存于 `benchmark-results/validation-current/`，时间种子为 `1795250503`。
  总计 1009 例，579 例通过；随机普通规划 576/1000（57.60%），固定普通规划 2/6，
  动力学示例 1/1，指定速度示例 0/2。
- 随机失败中，4 例前端无路，420 例外层 6 轮耗尽仍有碰撞；本批没有 OSQP 未收敛状态。
  随机单次总耗时平均 9.934 ms，P95 21.757 ms，最大 76.407 ms。

测试结果随种子和机器负载变化，不代表避障算法已改进。默认结果目录被 Git 忽略，
迁移项目时需要单独保留希望继续复现的历史目录。精确逐例记录、依赖及耗时见报告。

已知限制仍包括：OSQP 内部时间限制 setter 的兼容问题，以及原碰撞修复策略不保证收敛。
新增诊断仅说明退出原因，不增强连续曲线安全性或机器人动力学保证。
